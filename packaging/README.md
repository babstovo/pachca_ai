# Пачка AI

Переносимый клиент для Windows x64. Нужны Microsoft Edge, среда выполнения Microsoft Edge WebView2 и настольный Codex. Node.js входит в портативный EXE.

Когда собеседник просит нарисовать картинку, подключённый агент показывает запрос и чат в правой панели. Выберите вопрос и ответьте «да» для генерации и отправки или «нет» для отмены. Можно заранее поручить генерацию картинки для выбранного чата. Поручение сохраняется после закрытия приложения. При следующем подключении агент проверит переписку за время отсутствия. Если генератор не сможет сделать картинку, агент один раз напишет об этом в исходный чат. После отправки в панели появится ссылка на сообщение.

## Подключение

Войдите под своим аккаунтом Пачки. Список участников и чатов клиент получает из выбранного пространства. В разделе «Рассказать о себе» можно задать свои правила и стиль ответов. У нового профиля эти поля пустые.

Если агенту нужен постоянный контакт проджект-менеджера, укажите в локальном файле `%LOCALAPPDATA%\PachcaWebClient\workspace.local.json` строковое поле `managerNickname` с ником участника своей команды и перезапустите клиент. При редактировании сохраните остальные поля файла. По умолчанию контакт пуст.

Откройте «Настройки агента» → «Доска задач» → «Настроить». Вставьте HTTPS-ссылку из адресной строки открытой доски (например, `https://example.org/projects/demo/boards/1`) и API-ключ своего аккаунта OpenProject. Нажмите «Проверить и сохранить». Подключение доступно при отключённом агенте. Адрес хранится локально, ключ защищён средствами Windows и привязан к серверу и пространству Пачки.

## Обновление клиента

Клиент проверяет последний стабильный релиз на GitHub при запуске и каждые пять минут, в том числе в трее. Кнопка «Доступно обновление» в шапке скачивает новый EXE во временную папку рядом с текущим, сверяет его размер, SHA-256 и версию. Пачка закрывается, заменяет EXE по тому же пути, запускает новую версию и удаляет временную папку. Для установки нужны права записи в папку клиента. При первом запуске каждой версии зависимости извлекаются в `%LOCALAPPDATA%\PachcaWebClient\runtime`. Исходный ярлык продолжает работать. При отсутствии сети клиент открывается как обычно.

## Первый запуск

1. Сохраните `Pachca-AI-win-portable-x64.exe` в постоянной папке.
2. Запустите `Pachca-AI-win-portable-x64.exe` и войдите в Пачку в основном окне. Нажмите «Агент», затем «Подключить агента» в центре панели. Если доступно несколько пространств, выберите нужное. Агент использует открытый сеанс Пачки.
3. В разделе «Ответы» выберите MCP-клиент для инструментов Пачки. Для Codex доступны модель и уровень рассуждения. GitHub Copilot в VS Code получает регистрацию в пользовательском `mcp-config.json`. Для «Другой MCP-клиент…» выберите в диалоге JSON- или JSONC-файл клиента с разделом `mcpServers` или `servers`. Клиент должен поддерживать локальные серверы stdio. Если клиент предложит подтвердить запуск сервера, подтвердите его в самом клиенте. Модель внешнего клиента выбирается в нём. Встроенные ответы и анализ карточек Пачки AI используют Codex.
4. При необходимости подключите OpenProject в разделе «Доска задач».

Через MCP инструменты Пачки доступны в проектах текущего пользователя Codex. Для работы через подключённое окно оставьте Пачку AI открытой или сверните её в трей. Для отдельного подключения через командную строку предусмотрена команда `Pachca-AI-win-portable-x64.exe connect`.

Инструменты читают чаты, историю, треды и поиск Пачки. Codex запрашивает разрешение на отправку в соответствии с политикой рабочей области. Инструмент OpenProject возвращает назначенные на вошедшего пользователя карточки с вашей доски, включая статус, срок и ссылку. Если у коллеги разные имена в Пачке и OpenProject, исполнитель определяется по его аккаунту в OpenProject.

Сессии хранятся на компьютере пользователя Windows. Если срок действия сессии закончился, снова запустите соответствующий вход. Ключ API для входа не нужен.

## Входящие Пачки в реальном времени

`Pachca-AI-win-portable-x64.exe` открывает оригинальную веб-Пачку. Если наблюдение уже работает, окно подключается к нему. Крестик сворачивает окно в трей. Двойной щелчок по значку открывает окно снова. Пункт «Выход» в меню значка останавливает наблюдение и закрывает приложение.

Для разбора входящих нужен вход в Codex на этом компьютере. Вопросы по входящим сообщениям появляются в правой панели. Выберите вопрос и напишите агенту, что ответить. Журнал фонового сервиса можно открыть из меню трея.

После отправки ответа из панели вопросов клиент запоминает реплику собеседника, вопрос агента, ваше пояснение и итоговый текст. На этом компьютере хранятся последние 150 таких примеров. Если тот же собеседник в том же чате переформулирует вопрос, агент учитывает прежнее решение и отвечает самостоятельно. Для нового обязательства или разового разрешения агент снова обратится к вам.

Кнопка «Рассказать о себе» открывает описание, стиль и правила общения для текущего профиля Пачки. Сохранённые поля учитываются в автоответах, поручениях и черновиках. Например, укажите свою роль, предпочтение писать кратко на «ты» и правило уточнять у вас сроки. Хранение настроек локальное и отдельное для каждого профиля.

При первом подключении автоответы выключены. Когда на новое личное сообщение, упоминание или прямой ответ подготовлен текст, в чате агента появляется черновик. В карточке видны получатель, исходная реплика и предлагаемый ответ. «Отправить» публикует текст в указанной переписке, «Пропустить» убирает черновик. Если данных для ответа мало, Codex задаёт вам вопрос.

После включения автоответов Codex сам отвечает на приветствия, благодарности и безобидные шутки. На странную реплику в дружеском разговоре он может ответить лёгкой шуткой или попросить собеседника пояснить. К владельцу Codex обращается за фактами, сроками и решениями. Свои правила можно задать в окне «Рассказать о себе».

Чтобы написать Codex из Пачки, отправьте в «Избранном» сообщение вроде `/codex Помоги сформулировать ответ`. Клиент передаёт запрос в отдельный сеанс Codex на этом компьютере. Ответ появится в журнале событий в меню трея. Команда работает только для собственных сообщений из чата с самим собой.

Слева каналы, беседы и личные сообщения со счётчиками Пачки. При запуске с включёнными автоответами Codex также проверяет непрочитанные личные сообщения, упоминания и прямые ответы. Уже обработанные и получившие более свежий ответ сообщения пропускаются.

История сообщений, треды, реакции и вложения открываются в веб-интерфейсе Пачки.

Справа переписка с Codex. В меню «⋯» можно переключиться на список вопросов или снять выбранный вопрос. Подтверждение отправки включается в настройках агента, в разделе «Ответы». В черновике есть галочка «Больше не спрашивать, если получатель один». Если найдено несколько адресатов, Пачка AI покажет выбор. Связанные реплики собеседника разбираются вместе, а ответ Codex отправляется обычным сообщением без цитаты.

После подключения профиля правая панель восстанавливает последние 100 сообщений с агентом, миниатюры и ссылки. История хранится на этом компьютере отдельно для каждого профиля Пачки.

Кнопка «Подключить агента» в центре панели запускает подключение MCP. После подключения чат открывается автоматически. Панель загружает OpenAI ChatKit с CDN OpenAI. Если виджет недоступен, в локальном чате можно читать историю, писать агенту и прикреплять изображения. Запросы обрабатывает установленный на компьютере Codex под вашим текущим входом.

Когда Codex ждёт ответа, Пачка AI показывает уведомление Windows, в том числе из трея. Нажмите уведомление, чтобы открыть вопрос или список новых вопросов.

Кнопка «Журнал» в шапке открывает ленту действий в ChatKit. Число рядом с кнопкой показывает, сколько действий сейчас выполняется. В карточке видны время, адресат, текст и результат. Фильтры «В работе» и «Отправлено» помогают найти нужное сообщение. Кнопка «Открыть сообщение» ведёт к нему в Пачке.

Пока агент готовит ответ, его можно остановить в карточке. Готовое сообщение остаётся доступно для отмены ещё 10 секунд. Когда запрос на отправку уже передан Пачке, журнал показывает «Отправляется». Если ответ сервера потерялся, появится статус «Отправка не подтверждена». Откройте переписку, чтобы проверить результат.

Windows уведомляет об отправках, выполненных поручениях и ошибках. Когда Пачка свёрнута, уведомление также сообщает о готовом к отправке сообщении. Нажатие открывает журнал. Последние 250 завершённых действий хранятся на компьютере отдельно для каждого пространства.

Из правого чата можно написать другому человеку, даже когда открыта текущая переписка или выбран вопрос Codex. Укажите имя получателя из вашего пространства и текст сообщения. В окне подтверждения проверьте имя получателя перед отправкой.

Нажмите Ctrl+V в поле Codex, чтобы приложить картинку из буфера. Миниатюра появится под полем. Кнопка × убирает вложение до отправки. Можно отправить до трёх картинок без текста или с подписью.

Переключатель «Автоответы» сохраняется отдельно для каждого профиля. Красная кнопка «Отключить агента» внизу слева отключает инструменты Пачки у выбранного клиента, останавливает помощника и сворачивает его панель. Кнопка становится синей. Теперь можно выбрать другой клиент и подключиться снова. Открытый чат Пачки сохраняется. Для выхода из самой Пачки используйте меню аккаунта в мессенджере.

В «Проектах» можно подключить OpenProject и выбрать локальные папки. По просьбе владельца в правой панели агент ищет данные в файлах выбранного проекта и может подготовить по ним сообщение для коллеги. Для вопросов о текущей работе Codex проверяет ветки, изменённые файлы и недавние коммиты. Для запроса «Мои задачи в OpenProject» клиент использует ID аккаунта из API и показывает открытые карточки, назначенные на него. После списка можно указать «Переведи эти задачи в завершённые». Клиент проверит переходы и покажет их для подтверждения. Если подходящий вопрос приходит в Пачку, включённые автоответы сначала сообщат «Сейчас проверю», затем отправят результат проверки.

В «Доска задач» → «API-ключ OpenProject» можно подключить ключ аккаунта OpenProject. Ключ проверяется для этого сервера и хранится локально в защищённом хранилище Windows. В этом же разделе можно заменить или удалить сохранённый ключ. Клиент использует ключ для запросов к OpenProject без входа в браузере. Примеры запросов в правом чате — «Какой статус задачи #123?» и «Поставь задаче #123 статус В работе». Перед сменой статуса клиент показывает текущий и новый статус. OpenProject применит изменение после подтверждения, если аккаунт имеет права и переход разрешён workflow.

При открытии Пачки стикеры показывают ваши открытые задачи с подключённой доски. В разделе «Доска задач» нажмите «Выбрать статусы», чтобы оставить нужные карточки в оверлее. Выбор сохраняется для этой доски и пространства Пачки. Крестик закрывает стикеры и выключает автопоказ до следующего нажатия «Мои задачи» в шапке или в меню трея.

Щелчок по стикеру открывает карточку задачи. В «Настройки агента» → «Доска задач» можно выбрать открытие в Пачке или в браузере и включить или выключить автопоказ. Положение и размер панели сохраняются после перетаскивания. Кнопка «Сбросить настройки панели» возвращает исходный размер и положение вверху экрана, включает автопоказ и открытие задач в Пачке.

Наведите указатель на стикер или выберите его клавишей Tab, чтобы увеличить листок и увидеть статус и срок. Колесо прокручивает ряд как над карточками, так и между ними. Частично обрезанные листочки становятся полупрозрачными. Перетаскивайте ряд за любой листок в пределах рабочей области монитора. Потяните за загнутый нижний правый угол, чтобы изменить размер. Кнопка ↻ рядом со стикерами обновляет список.

Пункт «Доска OpenProject» в меню трея открывает назначенные вам открытые и закрытые задачи с подключённой доски. Здесь можно привязать ключ, посмотреть карточку и изменить её статус. При включённых автоответах на сообщение указанного в настройках менеджера о баге без задачи агент просит создать задачу в OpenProject и прислать ссылку в ту же переписке.

Для работы над кодом откройте «Настройки агента» → «Проекты» и выберите готовые локальные проекты из списка вашего настольного Codex. Для каждой папки репозитория можно сохранить назначение, модель и уровень рассуждения. Если папку добавляли в прежней версии Пачки и ей соответствуют несколько проектов Codex, укажите нужный проект в настройках. Пачка запоминает выбор по ID, поэтому переименование проекта сохраняет привязку.

В карточке открытой задачи нажмите «Создать чат задачи». Если задача затрагивает несколько репозиториев, в каждом выбранном проекте Codex появится свой чат, например `4500_task`. Переключатель «Автосоздание чатов задач» включает автоматическую передачу ТЗ для назначенных вам задач на изменение кода, когда репозиторий определён однозначно. Публикация новостей, согласования и встречи остаются в OpenProject.

Пачка передаёт ТЗ и доступные вложения в чат в основной папке проекта. Первым ответом Codex подтверждает получение. Когда будете готовы, выберите ветку в локальном репозитории и напишите «Начинай» в чате. Обновления ТЗ из Пачки тоже требуют только подтверждения получения. Из карточки можно повторно открыть сохранённый чат.

Модель и уровень рассуждения выбираются в разделе «Ответы» настроек агента. У каждого варианта показаны уровни, которые поддерживает установленный Codex. Оба параметра применяются к новым ответам и черновикам и сохраняются для текущего профиля Пачки.

Codex читает поддерживаемые входящие ссылки в фоне и учитывает их содержимое в ответах.

Кнопка «☺» вставляет эмодзи в поле ввода. Кнопка «☺+» рядом с сообщением открывает выбор реакции, включая эмодзи пространства. Нажмите на уже поставленную вами реакцию, чтобы снять её.

Анализ переписки для карточек запускается вручную. В меню «Участники и стиль ответов» найдите нужных людей по имени, отметьте их, укажите число последних сообщений на человека и нажмите «Обновить выбранных». Список и поиск используют профили участников. При открытии окна все галочки сняты. Для ручного анализа предложен лимит 100 реплик на человека. Выборка включает сообщения участника и ваши адресные ответы. Поиск реплик охватывает до 5 000 сообщений в личных чатах выбранных людей, общих чатах и тредах.

Для каждого отмеченного человека подключённый Codex отдельно разбирает текст реплик. В карточке появятся рабочий портрет, манера общения, советы по ответу и примеры из переписки. Счётчик показывает фактический объём выборки. Портрет сохраняется до следующего ручного обновления. Свои формулировки можно задать через «Редактировать»; они имеют приоритет при подготовке ответа.

## Командная строка

```powershell
.\Pachca-AI-win-portable-x64.exe --help
.\Pachca-AI-win-portable-x64.exe profiles
.\Pachca-AI-win-portable-x64.exe search chats 'Разработка'
.\Pachca-AI-win-portable-x64.exe history 123 --limit 10
.\Pachca-AI-win-portable-x64.exe openproject-tasks
.\Pachca-AI-win-portable-x64.exe inbox
```
