# Пачка AI

Клиент Пачки для Windows, в котором можно обсудить переписку с агентом, проверить предложенный ответ и открыть свои задачи из OpenProject.

**[Скачать для Windows x64](https://github.com/babstovo/pachca_ai/releases/latest/download/Pachca-AI-win-portable-x64.exe)** · [Что изменилось](https://github.com/babstovo/pachca_ai/releases)

## Первый запуск

1. Сохраните приложение в постоянную папку, запустите его и войдите в Пачку.
2. Чтобы пользоваться агентом, откройте панель **Агент** и нажмите **Подключить агента**. Пачка сама найдёт установленный Codex. Если потребуется, войдите в свой аккаунт.
3. Если вы пользуетесь OpenProject, откройте **Настройки агента → Доска задач → Настроить**. Укажите ссылку на доску и API-ключ своего аккаунта. Доску можно подключить отдельно от агента.

## Ответы на сообщения

По умолчанию автоответы выключены. Когда агент подготовит ответ, в его чате появится черновик с получателем, исходным сообщением и предложенным текстом. Нажмите **Отправить**, чтобы ответить в нужной переписке, или **Пропустить**, чтобы убрать черновик.

В разделе **Рассказать о себе** можно указать свою роль и предпочтительный стиль общения. Агент учтёт их при подготовке ответов.

## Задачи с вашей доски

Кнопка **Мои задачи** открывает панель с карточками, назначенными вам на выбранной доске. В настройках доски отметьте статусы, которые хотите видеть в оверлее. Например, можно оставить только задачи в работе и на проверке. Нажмите на карточку, чтобы открыть задачу.

Когда появится новая версия, в шапке приложения появится кнопка **Доступно обновление**.
